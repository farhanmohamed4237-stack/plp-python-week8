
# Personal Mini-Toolkit

## PLP Python Week 8 Final Project

### Project Description

The Personal Mini-Toolkit is a menu-driven Python program that provides three useful tools. It demonstrates Python concepts such as variables, input and output, conditionals, loops, lists, functions, and f-strings.

## Features

### 1. Simple Calculator
- Adds two numbers.
- Subtracts two numbers.
- Multiplies two numbers.
- Divides two numbers.
- Handles invalid numbers and division by zero.

### 2. To-Do List Manager
- Adds new tasks.
- Displays saved tasks.
- Removes completed or unwanted tasks.
- Stores tasks in a list while the program is running.

### 3. Number Guessing Game
- Generates a random number between 1 and 10.
- Allows the user to guess the number.
- Gives hints when a guess is too high or too low.
- Counts the number of attempts.

## How to Run the Program

1. Install Python 3 on your computer.
2. Download or clone this GitHub repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

```bash
python toolkit.py
```

5. Select a tool from the main menu.
6. Follow the instructions displayed in the terminal.
7. Select option 4 from the main menu to quit.

## Reflection

Building this Personal Mini-Toolkit helped me understand how different Python concepts work together in one program. The most challenging part was organizing the code and making sure the indentation was correct. I encountered an indentation problem while connecting the calculator to the main menu, and fixing it took the most time. I solved the problem by replacing the incorrect code with a properly formatted version. I also learned how to use lists to add, display, and remove tasks. Testing the Number Guessing Game helped me understand loops and conditional statements better. With one more week, I would add a feature that saves the to-do list to a file so tasks remain available after closing the program.
