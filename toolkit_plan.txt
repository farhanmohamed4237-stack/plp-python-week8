PERSONAL MINI-TOOLKIT - PROJECT PLAN

1. PROJECT DESCRIPTION
This Python program provides three useful tools through a simple menu.

2. TOOLS
Tool 1: Simple Calculator
This tool allows the user to add, subtract, multiply, or divide two numbers.

Tool 2: To-Do List Manager
This tool allows the user to add, view, and remove tasks from a list.

Tool 3: Number Guessing Game
This tool lets the user guess a secret number and provides hints until the correct number is guessed.
